# auto-develop-game-skill
校园杀手游全自动基础架构脚手架。集成3套游戏引擎（Unity / Python / H5+Capacitor）与3套UI引擎（FairyGUI / UGUI / HTML+CSS），内置30张卡牌×23角色×37技能×5阵营的纯JSON分类库，附带10个自动化安装/构建/测试脚本，覆盖 CI/CD（GitHub Actions）+ 运维引擎（Docker+ELK+Grafana+Loki+Prometheus）全链路。32份 AI 提示词均内置验证门禁，真正做到 git clone → install-all.bat → 一键搭建可上线手游。
